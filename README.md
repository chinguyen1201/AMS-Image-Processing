# AMS-Image-Processing
Educational image processing project in Python implementing basic filters (brightness, contrast, flip, grayscale, blur/sharpen, circular mask) with NumPy and Pillow.

The project for the course **Applied Mathematics and Statistics - MTH00057 - HCMUS**
